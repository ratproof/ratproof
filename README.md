## About

I build and run Discord bots and communities, write the backend that powers them, and put together web projects on the side. Most of my work is Python on a Linux VPS with PostgreSQL behind it, plus frontend projects deployed on Vercel.

- Build bots with slash commands, cogs, and database-backed features
- Host and maintain my own services on an Ubuntu VPS
- Ship small web apps and tools, from calculators to browser-based simulators
- Manage multiple Discord communities, so I build for real users

## How I Work

- Readable code over clever code
- Modular structure so features can be added without rewrites
- Environment variables for config, never hardcoded secrets
- Parameterized queries and proper input handling
- Logging and error handling so problems are easy to find
- Small, focused commits with clear messages
